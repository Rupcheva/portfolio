# Yulia Rupcheva — homepage UI draft

Open index.html in a browser, or run `python3 -m http.server 4173` from this directory. No build or dependencies required.

The six current projects follow the requested order. The Claude Code video project is deferred until the rest is ready. Copy, colours, portrait, and project artwork are provisional. “Case study” labels are intentionally noninteractive until destinations are supplied; the Behance contact link and page navigation work.

Theme variables are at the top of styles.css. Replace the placeholder image containers with real images later.

For GitHub Pages: upload these files to the root of the public Rupcheva.github.io repository, then enable Settings → Pages → Deploy from a branch → main / root.
